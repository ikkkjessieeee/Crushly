# Crushly Cyber Heartbeat Waitlist

Animated mobile-first waitlist landing page for the USC beta.

## Preview

```bash
node scripts/serve.mjs crushly-cyber-waitlist 4182
```

Open `http://127.0.0.1:4182`.

## Deploy

Deploy the `crushly-cyber-waitlist` folder as a static site. The waitlist buttons open the existing Tally form in a branded modal.
