# Crushly Waitlist

Mobile-first waitlist landing page for the USC private beta.

## Preview locally

From the repository root:

```bash
node scripts/serve.mjs crushly-waitlist 4180
```

Open `http://127.0.0.1:4180`.

## Deploy

Deploy the `crushly-waitlist` folder as a static site on Netlify, Vercel, or GitHub Pages.

The primary CTA opens the existing Tally waitlist form inside a branded modal. The direct form URL remains available as a fallback.
